# 🚀 Sanket Kongare - Interactive Developer Portfolio

An interactive, responsive portfolio web application engineered with **React 18**, **TypeScript**, **Tailwind CSS**, and **Motion**. Designed to showcase engineering projects, certifications, technical skill proficiencies, and direct client messaging.

---

## 🌟 Key Features

- ⚡ **Interactive Hero & Live Terminal**: Interactive tech stack inspector, dynamic role typist, and system status indicators.
- 📂 **Rich Project Showcase**: Categorized project filter (AI/ML, IoT, Web & Systems, Data Analytics) with deep-dive modal viewports, architecture diagrams, and GitHub repository links.
- 📜 **Verified Certifications & Credentials**: Certificate viewer with verification credential links (Microsoft PL-300, AWS, etc.).
- 📊 **Skills Radar & Proficiency Matrix**: Comprehensive breakdown of languages, frameworks, developer tools, and domain specializations.
- ✉️ **Direct Contact & EmailJS Integration**: Integrated contact form with seamless delivery to personal inbox via EmailJS.
- 📄 **Interactive Resume Viewer**: Embedded modal preview with direct download capability.
- 🎨 **Silicon Valley Dark Theme**: Ambient glow, subtle animated light strips, high contrast typography, and accessible responsive design.

---

## 🛠️ Tech Stack & Dependencies

- **Frontend**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React (Icons)
- **Animations**: `motion` (Framer Motion)
- **Messaging**: `@emailjs/browser`
- **Data Visualization**: Recharts / D3
